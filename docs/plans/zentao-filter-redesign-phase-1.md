# Plan: zentao-filter-redesign phase 1 — FilterState + FilterTickets

## Context

Add 4 filter dimensions (severity, assignee, bug type, resolution) to the board
filter model and apply them in the pure filtering use case. Additive only — the
new fields default to empty, so existing behavior is unchanged until the UI wires
them up in a later phase.

## Constraints

- NO refactoring/renaming beyond what is written below.
- NO edits outside the 3 files in this plan.
- Near-miss (do NOT touch): `build_board.dart`, `build_zentao_bug_board.dart`,
  `build_zentao_task_board.dart`, `build_list.dart`, `saved_view.dart`. They
  consume `FilterTickets`/`FilterState` but need no change.
- Do NOT hand-edit `filter_state.freezed.dart` — it is regenerated by `make codegen`.
- Escape hatch: if a quoted "current state" block does not match the file, or a
  verify command fails twice → STOP and report the blocker; do not improvise.

### Step 3: tests for the new facets — `test/domain/board_logic_test.dart`

- Current state (imports, lines ~1–13) already import `Ticket`, `Priority`,
  `ProviderType`, `UnifiedStatus`, `FilterState`, `FilterTickets`. Add one import
  after the existing `unified_status.dart` import line:
  ```dart
  import 'package:work_nexus/core/domain/entities/provider_entity.dart';
  ```
- Current state — the `_ztBug` helper already accepts `severity`. Inside
  `group('FilterTickets', () {`, add these tests after the existing
  `test('search matches title, key, and labels case-insensitively', ...)` test:
  ```dart
    test('severity filter keeps only matching severities', () {
      final tickets = [
        _ztBug(id: 'crit', providerStatus: 'active', severity: 1),
        _ztBug(id: 'minor', providerStatus: 'active', severity: 3),
      ];
      final out = filter(_q(tickets, const FilterState(severities: {1})));
      expect(out.map((t) => t.id), ['crit']);
    });

    test('assignee filter matches names and unassigned via empty sentinel', () {
      final tickets = [
        _ztBug(
          id: 'mine',
          providerStatus: 'active',
        ).copyWith(assignee: 'Thanh'),
        _ztBug(id: 'none', providerStatus: 'active'),
      ];
      expect(
        filter(
          _q(tickets, const FilterState(assignees: {'Thanh'})),
        ).map((t) => t.id),
        ['mine'],
      );
      expect(
        filter(
          _q(tickets, const FilterState(assignees: {''})),
        ).map((t) => t.id),
        ['none'],
      );
    });

    test('bug type + resolution filters read the provider entity', () {
      final tickets = [
        _ztBug(id: 'code', providerStatus: 'active').copyWith(
          providerEntity: const ZenTaoBugEntity(bugType: 'codeerror'),
        ),
        _ztBug(id: 'cfg', providerStatus: 'active').copyWith(
          providerEntity: const ZenTaoBugEntity(bugType: 'config'),
        ),
        _ztBug(
          id: 'fixed',
          providerStatus: 'resolved',
          resolution: 'fixed',
        ).copyWith(
          providerEntity: const ZenTaoBugEntity(resolution: 'fixed'),
        ),
      ];
      expect(
        filter(
          _q(tickets, const FilterState(bugTypes: {'codeerror'})),
        ).map((t) => t.id),
        ['code'],
      );
      expect(
        filter(
          _q(tickets, const FilterState(resolutions: {'fixed'})),
        ).map((t) => t.id),
        ['fixed'],
      );
    });
  ```
- Follow the pattern of the surrounding tests in this same file (`_ztBug`, `_q`,
  `filter`, `expect(out.map((t) => t.id), [...])`).
- Verify: `fvm flutter test test/domain/board_logic_test.dart` → expected:
